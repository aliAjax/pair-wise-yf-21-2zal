# 手工地毯清洗排期台

给手工地毯清洗工作室使用的排期前台：登记地毯编号、产地、清洗池与预计时长，按池排期，跟踪清洗/脱色挂起/固色/完工状态。

## 业务规则

- **同池同时段只接待一条地毯**：排期按“入池分钟 + 预计时长”判定区间，结束时刻贴边也算压边（湿毯与换水需要缓冲）。
- **批量排期整单制**：一批多行先统一预检，任一地毯与已排时段压边、超出该池当日开放容量，或同一条地毯在两个池的时段压边，**整批退回**，池排期与档案保持原样，不产生部分写入。
- **脱色挂起**：清洗中发现脱色可挂起，挂起单仍占用池位（参与冲突判定），但不能标记完工；必须补做固色登记，登记成功后自动恢复清洗，才可完工。
- 数据保存在浏览器 `localStorage`，刷新不丢失；无任何新增依赖。

## 模块划分

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 排期规则 | `src/business/scheduling.ts` | 清洗池容量、压边判定、批量整单校验（纯函数）、清洗状态流转 |
| 状态存取 | `src/business/storage.ts` | localStorage 仓库、React store、档案/排期/固色等写操作（整批先校验后提交） |
| 列表筛选 | `src/business/filtering.ts` | 档案行视图派生、关键字/产地/池/状态筛选、当日池位看板分组（纯函数） |
| 界面 | `src/components/*` | 登记表、批量排期、池位看板、档案列表 |
