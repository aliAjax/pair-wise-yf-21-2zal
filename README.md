# 手工地毯清洗排期台

给手工地毯清洗工作室使用的单页排期工具：登记地毯编号与产地，把地毯批量排进各清洗池，
跟踪清洗中脱色挂起与固色续作。数据只存浏览器本地（localStorage），不新增任何依赖。

## 业务规则

- **档案登记**：地毯编号 + 产地；编号不可重复；已有排期的地毯不能删档案。
- **池位互斥**：同一清洗池同一时段只接待一条地毯。时段按闭区间判定，首尾相接（压边）也算冲突。
- **当日容量**：每池有当日容量上限（分钟），所有状态的条目（含挂起、已完工）都计入占用。
- **批量原子性**：批量提交时逐行校验字段、压边（含批内互撞与撞已排条目）和当日容量；
  只要任一行触雷，**整批退回**，池排期与档案保持原样，并列出全部原因。
- **脱色挂起**：清洗中发现脱色即挂起；池位保留（继续挡住压边与容量），不能标记完工。
- **固色续作**：挂起条目必须补做固色登记（做法/用料/操作人），登记后自动回到“清洗中”，
  固色记录随条目可查。

## 代码结构（规则 / 存取 / 筛选分离）

| 模块 | 职责 |
| --- | --- |
| `src/business/schedulingRules.ts` | 排期规则：压边判定（闭区间）、当日容量、批量事务校验、状态流转 |
| `src/business/persistence.ts` | 状态存取：localStorage 读写、结构校验、`usePersistentState` hook |
| `src/business/filtering.ts` | 列表筛选：档案/排期的纯函数筛选、排序与池当日用量统计 |
| `src/business/types.ts` | 领域模型类型 |
| `src/business/format.ts` | 时间/时长格式化与零依赖 ID |
| `src/business/seed.ts` | 首次打开的演示数据 |
| `src/components/` | `ArchivePanel`（档案）、`BatchPanel`（批量排期）、`ScheduleBoard`（看板与固色登记） |

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62009。页面右上角“恢复演示数据”可清空本机数据并重置。
